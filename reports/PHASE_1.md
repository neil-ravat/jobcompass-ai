## Implemented behavior

GET /health, /jobs and /recommendations read real normalized snapshots. Keyword,
role, country, remote-only and minimum salary filters are implemented. Missing
country eligibility is never eligible; a salary constraint requires a known
minimum in matching currency and pay period. Remote advertising does not imply
worldwide eligibility. Scores expose title/description/category components at
60/30/10 weights. Ties use source update time and source identity. Stale data
returns a clear 503; invalid inputs return 422; empty matches return an empty list.

## Architecture and tradeoffs

Read-only API over the existing JSON contract; no upstream request on every GET.
Pure filtering/ranking functions can be reused by database and LLM workflows.
Exact keyword matching is explainable but lacks semantic synonyms, addressed next.
